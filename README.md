# JETSYNC AI

JETSYNC AI is an AI-powered game day companion built for New York Jets fans.

## Overview
JETSYNC AI brings live game insights, AI commentary, fantasy guidance, and social fan connection into one experience.

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — landing page and pitch website
- `styles.css` — visual design and responsive layout
- `script.js` — small UI enhancement
- `PITCH.md` — concise product pitch and business summary
